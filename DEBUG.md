# Руководство по отладке Pi-Archiver Ultra

## 📋 Диагностика проблем

### 1. Проверка логов операций
```bash
# Просмотр логов в реальном времени
tail -f /var/log/pi-archiver/archiver.log

# Все логи
cat /var/log/pi-archiver/archiver.log
```

### 2. Анализ прогресса генерации π

**Проблема:** Прогресс зависает на 99.5%
**Причина:** Нелинейная сложность алгоритма Chudnovsky

**Решение:** Включить детальное логирование
```bash
pi-archiver archive file.txt --verbose
```

### 3. Проверка системных компонентов

**GPU поддержка:**
```bash
clinfo
```

**OpenCL устройства:**
```bash
ls /dev/dri/
```

**Память и CPU:**
```bash
free -h
nproc
```

### 4. Тестирование производительности

**Бенчмарк генерации:**
```bash
pi-benchmark --test-generation
```

**Тест с разной точностью:**
```bash
# Быстрый тест
pi-archiver archive file.txt --precision 10000

# Средний тест  
pi-archiver archive file.txt --precision 100000

# Полный тест
pi-archiver archive file.txt --precision 1000000
```

### 5. Распространенные проблемы

#### Проблема: "GPU генерация пока не реализована"
**Решение:** Использовать CPU или реализовать GPU

#### Проблема: Медленная генерация на 99%
**Причина:** Алгоритм Chudnovsky усложняется к концу
**Решение:** Это нормальное поведение

#### Проблема: Нелинейный прогресс
**Причина:** Упрощенная модель прогресса
**Решение:** Использовать логи для реального отслеживания

### 6. Опции отладки

```bash
# Включить детальное логирование
export PI_DEBUG=1
pi-archiver archive file.txt --verbose

# Проверить производительность
time pi-archiver archive file.txt --precision 100000

# Мониторинг ресурсов
htop
iotop
```

### 7. Файлы для анализа

**Логи:** `/var/log/pi-archiver/archiver.log`
**Конфиг:** `/etc/pi-archiver/config.json`
**Данные:** `/var/lib/pi-archiver/`
**Кэш π:** `/var/lib/pi-archiver/pi_storage/`

### 8. Команды диагностики

```bash
# Проверить установку
pi-archiver --version

# Тест генератора
pi-generator --digits 1000

# Полный бенчмарк
pi-benchmark

# Информация о системе
pi-archiver --info
```

## 🚨 Если ничего не помогает

1. **Собрать логи:** `journalctl -u pi-archiver`
2. **Проверить память:** `dmesg | grep -i memory`
3. **Переустановить:** `sudo ./uninstall.sh --full && sudo ./install_system.sh`
4. **Сообщить о проблеме:** Создать issue с логами
