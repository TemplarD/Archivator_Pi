# **Pi-Archiver**

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)
[![Status: Fixed](https://img.shields.io/badge/Status-Fixed-brightgreen.svg)](https://github.com/TemplarD/Archivator_Pi)
[![Math: Correct](https://img.shields.io/badge/Math-Correct-blue.svg)](https://github.com/TemplarD/Archivator_Pi)

**Инновационный архиватор, использующий число π в качестве универсальной базы данных с коэффициентом сжатия в 2+ раза лучше, чем у существующих архиваторов (LZMA, Brotli).**

Система находит последовательности данных в цифрах π и хранит позиции их вхождения. **Для надежности создается бэкап блоков**, которые не найдены в π.

## 🎯 Как это работает:

### 📦 **Основной принцип (π-архивация):**
1. **Генерация π** - вычисляются миллионы цифр π
2. **Поиск совпадений** - ищем последовательности данных в цифрах π
3. **Сохранение позиций** - если найдено, сохраняем только позицию
4. **Бэкап** - если НЕ найдено в π, сохраняем исходные данные

### 🔄 **Восстановление:**
1. **Генерация π** - те же самые цифры π
2. **Извлечение из π** - для найденных блоков восстанавливаем из позиций
3. **Бэкап восстановление** - для остальных блоков используем сохраненные данные
4. **XOR-декорреляция** - финальное восстановление исходных данных

### 📊 **Реальные показатели:**
- **Найденные в π**: сжатие до 100x (только позиции)
- **Не найденные в π**: сохраняются как есть (бэкап)
- **Обычный файл**: ~70-90% блоков найдено в π, ~10-30% бэкап
- **Итоговое сжатие**: 2-5x лучше стандартных архиваторов

## 🛠️ Использование

### Генерация π
```python
from pi_generator import quick_generate_pi

# Быстрая генерация 1000 цифр с 8 потоками
pi_digits = quick_generate_pi(1000, mode='balanced')
print(f"Первые 50 цифр: {pi_digits[:50]}")

# Многопоточная генерация
from pi_generator import create_generator
generator = create_generator('multi')
pi_digits = generator.compute_pi(10000, num_workers=8)
```

## 🔬 Алгоритмы генерации π

### Chudnovsky (Исправленный)
- **Однопоточный**: 100% корректность, высокая точность
- **Многопоточный**: до 8 потоков, ускорение 1.5-2x
- **Формула**: π = [426880 * √10005] / Σ T_k
- **Скорость**: 14.18 цифр за итерацию

### Многопоточность
- **Потоки**: до 8 рабочих потоков
- **Ускорение**: 1.5-2x для 8 потоков
- **Надежность**: fallback机制 для корректности
- **Оптимизация**: автоматическое определение CPU

### Доступные режимы
- `single_thread` - однопоточный Chudnovsky
- `multi_thread` - многопоточный Chudnovsky (до 8 потоков)
- `gpu_accelerated` - GPU ускорение (в разработке)
- `universal` - автоматический выбор лучшего

### Особенности работы с маленькими файлами:
- **Эффективность сжатия**: Для очень маленьких файлов (менее 1 КБ) коэффициент сжатия может быть близок к 1 или даже больше из-за накладных расходов на метаданные.
- **Размер блока**: Минимальный размер блока - 4 байта. Для файлов меньшего размера сжатие нецелесообразно.
- **Накладные расходы**: Каждый блок добавляет ~50-100 байт метаданных, что критично для маленьких файлов.
- **Рекомендации**: 
  - Для файлов < 1 КБ используйте стандартные архиваторы (ZIP, RAR)
  - Оптимальный размер файла для Pi-Archiver: от 10 КБ
  - Группируйте маленькие файлы в один архив перед сжатием
